# 드론쇼 만들기

**60AI만들기** 채널에서 만든 무료 도구입니다.
글씨나 모양을 넣으면 수천 개의 불빛이 밤하늘에 모여 드론쇼처럼 그려 줍니다.

👉 **https://60aimake.github.io/simple-drone-show/**

## 쓰는 법

1. 글씨를 치고 **띄우기**
2. 글씨체 · 굵기 · 속 빈 글씨 · 파노라마를 고릅니다
3. 모양(별 · 하트 · 꽃 · 비행기 · 로봇 · 얼굴 · 사람)도 됩니다
4. 사진을 불빛으로 바꾸거나 배경으로 깔 수 있습니다
5. 빛 색과 드론 대수(300~2,600)를 고릅니다
6. **저장** — 사진 또는 영상으로 내려받습니다

## 만든 것

- 사진은 기기 밖으로 나가지 않습니다. 브라우저 안에서만 처리합니다
- 설치 · 가입 · 광고 없습니다
